# Solo CEO Stack

> A free starter pack for solo founders to run a virtual organization
> of dozens of AI employees with Claude Code.

## What is this?

Solo CEO Stack is a collection of CLAUDE.md templates and AI employee prompts
designed to let one human run a virtual organization of dozens of AI employees.

This repository is the **free starter version** with 3 core executives.
The full 69-employee organization is available as a paid pack.

## Why?

Most "AI assistant" templates assume one human + one AI.
Solo CEO Stack assumes one human + many AIs working as an org.

This unlocks:
- Clear delegation: each AI has a defined role
- Composability: edit CLAUDE.md to "hire" or "fire"
- Scalability: the org grows without adding humans

## What's NOT included

Solo CEO Stack focuses purely on AI employee design.
The following are intentionally **excluded**:

- Streaming platform integrations
- Live streaming AI news systems
- Platform-specific monitoring scripts
- TTS pipelines
- Custom MCP integrations for proprietary use

## Quick Start

```bash
git clone https://github.com/nikkun22/solo-ceo-stack.git
cp solo-ceo-stack/templates/claude_md/CLAUDE.md ./CLAUDE.md
cp solo-ceo-stack/prompts/cxo/CEO.md ./.claude/
```

Open in Claude Code and start.
