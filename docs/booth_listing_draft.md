## 商品説明（日本語、約1000字）

### Solo CEO Stack Basic Pack とは

あなたが社長。あとは全員AIエージェント。

Solo CEO Stack Basic Packは、Claude Codeで動く仮想組織を即日構築するためのプロンプトパックです。CEO・CTO・CFOの3名からスタートした無料版をベースに、全16名のCxO（最高責任者）を完備しました。

### 16名のCxOが揃うと何が変わるか

無料版の3名では「作る・お金を管理する・意思決定する」しかできません。

Basic Packでは、以下が全て役割として分離されます：

- **COO**がCxO間の調整を一手に引き受け、社長の指示が組織全体に流れます
- **CMO**がブランドと集客を担当し、マーケティング判断を代行します
- **CSO**が営業パイプラインを管理し、顧客獲得から受注まで追跡します
- **CPO**がプロダクトロードマップを持ち、機能優先度の意思決定を担います
- **CISO × CRO**の二重防衛でリスクと情報セキュリティをカバーします

さらに、組織を運用するための実務テンプレートも同梱しています：

- **4階層組織図**：社長→CxO→部長→係長→一般スタッフ（69名）の全体像をMermaidで可視化
- **DRIマッピング**：6事業ライン × 担当CxOの責任分担表（プレースホルダー形式）
- **業務マニュアル雛形**：朝・昼・夜の日次フロー、週次レビュー、月次P&L、「社長が休んだ日」のオペレーション

### 設計思想

各プロンプトは「役割・権限・エスカレーションルール・禁止事項」を明確に定義しています。AIエージェントが勝手に越権行為をしないよう、境界を明示した設計です。

使い方は簡単です。プロンプトをCLAUDE.mdに貼り付け、Claude Codeを起動し、「@CFO: 今月のP&Lを出して」と入力するだけ。

このパックは、実際にソロで事業を運営する中で設計・検証されたプロンプトをベースにしています。

## セールスポイント

- **即日使える**：コピペで動く完成品プロンプト。設計不要
- **16名フルCxO**：CEO〜CROまで経営チーム全員が揃う
- **権限設計済み**：各CxOに escalation rules が内蔵されており、社長の判断が必要な場面を自動フラグ
- **日本語対応**：全プロンプトは英語ベースだが、Communication Style で日本語出力を指定済み
- **組織図付き**：Mermaidで4階層69名の組織全体像を可視化。Tier 3へのアップグレードパスも明示
- **運用マニュアル付き**：始めた翌日から使える日次・週次・月次の運用フロー
- **Claude Code最適化**：Claude Code（CLI）で使うことを前提に設計

## 推奨ユーザー像

**こんな方に最適です：**

- Claude Codeを使っていて「もっと組織的に使いたい」と感じているソロ起業家
- 会社の管理業務をAIエージェントに委任したいフリーランサー
- プロダクト・マーケティング・法務など複数部門を1人で兼任している経営者
- AIエージェント組織の設計に興味があるエンジニア・デザイナー

**こんな方には向きません：**

- Claude Code未使用で、導入予定もない方
- プロンプトの内容をそのまま使わず、大幅カスタマイズが必要な方（Enterpriseをご検討ください）
- チームで使うことを前提としている方（本製品はソロ運営向けです）
